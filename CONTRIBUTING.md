# Contributing

Thanks for helping improve Mintlane.

1. Create a focused branch from `main`.
2. Keep the project dependency-free unless a clear requirement justifies a dependency.
3. Preserve semantic HTML, keyboard access, responsive behavior, and reduced-motion support.
4. Run `npm run check` before opening a pull request.
5. Describe user-facing behavior and test coverage in the pull request.

Do not add real payment, wallet, or credential flows without a separate security review.
